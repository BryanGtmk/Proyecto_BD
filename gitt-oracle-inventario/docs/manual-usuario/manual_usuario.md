# Manual de usuario

## Inicio de sesion

Ingrese con el correo y contrasena asignados. Usuario de prueba: `admin@fisei.edu.ec` con `Admin123*`.

## Dashboard

Muestra indicadores de articulos, disponibilidad, prestamos activos, mantenimientos pendientes y notificaciones pendientes.

## Inventario

Permite consultar articulos, filtrar por codigo, nombre o estado, abrir el detalle, crear nuevos articulos y editar datos existentes. El detalle puede mostrar una imagen referencial y el valor estimado del articulo.

## Prestamos

Permite revisar prestamos registrados y crear un prestamo seleccionando usuario, fecha de devolucion y articulos disponibles.

## Devoluciones

Seleccione un prestamo activo y registre la devolucion. El sistema actualiza los articulos a DISPONIBLE y registra auditoria.

## Mantenimientos

Muestra mantenimientos preventivos y correctivos, con fecha, estado y observacion.

## Movimientos

Lista ingresos, traslados, prestamos, devoluciones y eventos de mantenimiento por articulo.

## Reportes

Incluye articulos disponibles, prestamos activos, valor total del inventario por departamento y movimientos recientes. La API tambien expone reportes por categoria y departamento.

## Auditoria

Permite revisar acciones criticas registradas por usuario, fecha, accion, tabla y descripcion.
