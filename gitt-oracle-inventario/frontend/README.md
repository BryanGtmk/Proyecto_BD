# Frontend GITT Oracle

Interfaz visual profesional del Sistema Web de Gestión de Inventario Tecnológico para la FISEI.

Esta version usa datos simulados y navegacion interna en React. No realiza autenticacion real ni consume una API; queda lista para conectarse luego a ASP.NET Core Web API con Oracle Database.

Tecnologias usadas:

- React + Vite
- Tailwind CSS
- Componentes locales estilo shadcn/ui
- Lucide React

```bash
npm install
npm run dev
```

Pantallas incluidas: login, dashboard, inventario, nuevo artículo, editar artículo, detalle de artículo, préstamos, nuevo préstamo, registrar devolución, mantenimientos, movimientos, usuarios, ubicaciones, categorías, reportes y auditoría.
