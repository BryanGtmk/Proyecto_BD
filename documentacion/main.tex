\subsection{Objetivos}

\subsubsection{Objetivo General}

Analizar y estructurar de una forma correcta la información que 
necesitaremos para desarrollar un sistema de préstamos e inventarios de la
Universidad Técnica de Ambato, Las cuales nos van a ayudar a poder identificar 
nuestros datos a través de entidades y atributos las cuales nos van a ayudar o 
tener una buena reglas de negocios para nuestro proyecto Y por último tener 
una forma correcta de la gestión y control de nuestros recursos tecnológicos aplicados.

\subsubsection{Objetivos Específicos}

\begin{itemize}

\item Identificar las diferencias que tenemos de 
nuestros datos con la información dentro de nuestro sistema.


\item Determinar la forma que las entidades y los atributos 
van a ayudarnos a representar la estructura básica de nuestra base de datos del proyecto.


\item Comprender las reglas de negocios las cual es vamos a 
utilizar para que podamos tener un funcionamiento del sistema bastante óptimo y sobre todo el control de equipos.


\end{itemize}

\subsection{Conclusiones}

\begin{itemize}

\item Gracias a la elaboración de este proyecto pudimos comprender las diferencias que hay 
entre nuestros datos y la información que nosotros vamos a aplicar dentro de nuestro sistema de 
préstamos de equipos de la Universidad técnica de Embato lo cual les pudimos identificar gracias a 
ejemplos investigados dentro de El entorno de nuestra institución.


\item Además pudimos identificar y definir de una forma muy práctica nuestras entidades y 
atributos los cuales nos vamos a necesitar para tener una estructura sólida de nuestra base 
de datos aplicadas en nuestro proyecto la cual nos va a ayudar a tener una organización más 
amplia sobre nuestra información relacional con los equipos que vamos a tener y las demás entidades.


\item Y por último podemos concluir que las velas que nosotros vamos a definir de negocio para 
nuestro programa nos ayudó bastante a establecer condiciones y restricciones sobre todo el uso de 
El correcto funcionamiento de nuestro sistema para lo que es aplicado en los préstamos las cuales 
nos van a ayudar a tener una forma mejorada de poder controlar y administrar nuestros recursos las 
cuales vamos a tener dentro de nuestra institución.


\end{itemize}

\subsection{Recomendaciones}

\begin{itemize}

\item Por la parte de recomendaciones podemos decir que para tener el desarrollo de nuestro modelo 
entidad relación tenemos que formar una parte gráfica de nuestras entidades y sobre todo tener las 
relaciones identificadas mentes bastantes claras en nuestro sistema.


\item Como otra recomendación tenemos la cual nos va a ayudar a tener una validación bastante en 
nuestras reglas de negocios lo que nosotros tenemos que hacer es definir bien nuestros requerimientos 
pero en forma real de nuestros laboratorios o las áreas responsables en las cuales van a trabajar 
tomando como ejemplo la entidad financiera o educativa en la cual vamos a desarrollar nuestro proyecto.


\item Y como última recomendación tenemos que aplicar correctamente nuestro modelo entidad 
relación para así tener su respectiva base de datos pero con un sistema bastante claro sobre la 
gestión de nuestros datos para realizar así unas pruebas correctas del funcionamiento de nuestro 
sistema aplicado.


\end{itemize}\cite{greenwade93}
