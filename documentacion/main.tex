\section{Informe de tarea}

\subsection{Objetivos}

\subsubsection{General}

Aplicar consultas SQL en Oracle utilizando sentencias de selección, filtros, ordenamiento, uniones, agrupaciones, funciones de agregación y subconsultas, mediante la base de datos \texttt{VETERINARIA\_DB}.

\subsubsection{Específicos}

\begin{itemize}
    \item Ejecutar consultas SQL mediante \texttt{SELECT}, \texttt{WHERE}, \texttt{ORDER BY}, \texttt{INNER JOIN}, \texttt{GROUP BY} y \texttt{HAVING}.
    \item Aplicar funciones de agregación como \texttt{COUNT}, \texttt{SUM}, \texttt{AVG}, \texttt{MAX} y \texttt{MIN}.
    \item Desarrollar consultas propias que integren uniones, agrupaciones, subconsultas y funciones de agregación.
\end{itemize}

\subsection{Explicación de las consultas propias}

\textbf{Consulta propia 1: Total de mascotas y peso promedio por propietario.}  
Esta consulta permite identificar cuántas mascotas tiene cada propietario y calcular el peso promedio de sus mascotas. Se utiliza \texttt{INNER JOIN} para relacionar propietarios con mascotas, \texttt{GROUP BY} para agrupar por propietario y funciones como \texttt{COUNT} y \texttt{AVG} para obtener los resultados agregados. Además, se aplica \texttt{HAVING} para filtrar los grupos según una condición.

\textbf{Consulta propia 2: Promedio y generación económica por especie.}  
Esta consulta permite analizar cuánto dinero han generado las consultas según la especie de la mascota. Para ello se relacionan las tablas \texttt{ESPECIE}, \texttt{MASCOTA} y \texttt{CONSULTA}. Se emplea \texttt{SUM} para calcular el total generado y \texttt{AVG} para obtener promedios de costos.

\textbf{Consulta propia 3: Veterinarios sobre el promedio de consultas o generación.}  
Esta consulta permite identificar veterinarios cuyo rendimiento económico o cantidad de consultas supera un promedio calculado mediante subconsulta. Se aplican agrupaciones por veterinario, funciones de agregación y la cláusula \texttt{HAVING} para filtrar los resultados agrupados.

\textbf{Consulta propia 4: Mascotas con mayor cantidad de consultas.}  
Esta consulta permite conocer qué mascotas registran una mayor cantidad de atenciones médicas. Se relacionan las tablas \texttt{MASCOTA} y \texttt{CONSULTA}, se agrupa por mascota y se utiliza \texttt{COUNT} para calcular el número de consultas realizadas.

\textbf{Consulta propia 5: Especialidades con mayor generación económica.}  
Esta consulta permite determinar qué especialidades veterinarias generan mayores ingresos. Se relacionan las tablas \texttt{ESPECIALIDAD} y \texttt{CONSULTA}, se agrupan los datos por especialidad y se utiliza \texttt{SUM} para calcular el total generado.

\subsection{Conclusiones}

La práctica permitió aplicar los principales fundamentos de consultas SQL en Oracle, utilizando filtros, ordenamiento, uniones, agrupaciones, funciones de agregación y subconsultas. Mediante la base de datos \texttt{VETERINARIA\_DB}, se logró consultar información relacionada entre propietarios, mascotas, veterinarios, especialidades y consultas médicas.

Además, el desarrollo de consultas propias permitió reforzar el uso combinado de \texttt{INNER JOIN}, \texttt{GROUP BY}, \texttt{HAVING}, subconsultas y funciones de agregación. \subsection{Recomendaciones}

Se recomienda verificar la conexión al usuario correcto antes de ejecutar las consultas, ya que trabajar con otro usuario puede generar errores relacionados con tablas inexistentes. También se recomienda ejecutar primero las sentencias de creación de tablas e inserción de datos antes de probar las consultas.

Además, es conveniente ordenar y nombrar correctamente las capturas de evidencia para facilitar su inclusión en el informe. En consultas con columnas de texto largas, se recomienda utilizar Oracle SQL Developer o ajustar la salida del terminal para visualizar los resultados de forma más clara.
