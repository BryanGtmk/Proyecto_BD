\section{Informe de tarea}

\subsection{Objetivos}

\subsubsection{General}

Aplicar consultas SQL en Oracle utilizando sentencias de selección, filtros, ordenamiento, uniones, agrupaciones, funciones de agregación y subconsultas, mediante la base de datos \texttt{VETERINARIA\_DB}.

\subsubsection{Específicos}

\begin{itemize}
    \item Ejecutar consultas SQL mediante \texttt{SELECT}, \texttt{WHERE}, \texttt{ORDER BY}, \texttt{INNER JOIN}, \texttt{GROUP BY} y \texttt{HAVING}.
    \item Aplicar funciones de agregación como \texttt{COUNT}, \texttt{SUM}, \texttt{AVG}, \texttt{MAX} y \texttt{MIN}.
    \item Desarrollar consultas propias que integren uniones, agrupaciones, subconsultas y funciones de agregación.
\end{itemize}

\subsection{Modalidad}

La actividad fue desarrollada de forma práctica, mediante la ejecución de sentencias SQL en Oracle. Se utilizó la base de datos \texttt{VETERINARIA\_DB}, la cual contiene tablas relacionadas con propietarios, mascotas, especies, veterinarios, especialidades y consultas médicas.

\subsection{Tiempo de duración}

\textbf{Presenciales:} desarrollo y revisión de la base de datos en clase.\\
\textbf{No presenciales:} ejecución de consultas, captura de evidencias y elaboración del informe.

\subsection{Instrucciones}

La tarea consistió en ejecutar consultas SQL sobre la base de datos \texttt{VETERINARIA\_DB}. Además, se desarrollaron cinco consultas propias cumpliendo con los requisitos establecidos.

\section{Descripción de la base de datos}

La base de datos empleada se denomina \texttt{VETERINARIA\_DB}. Esta base de datos permite registrar información relacionada con propietarios, mascotas, especies, veterinarios, especialidades y consultas médicas.

\textbf{Tabla} & \textbf{Descripción} \\
\midrule
\texttt{PROPIETARIO} & Almacena los datos personales de los dueños de las mascotas. \\
\texttt{ESPECIE} & Registra las especies de animales, como perro o gato. \\
\texttt{ESPECIALIDAD} & Almacena las especialidades veterinarias. \\
\texttt{VETERINARIO} & Contiene los datos de los veterinarios. \\

\subsection{Conclusiones}

La práctica permitió aplicar los principales fundamentos de consultas SQL en Oracle, utilizando filtros, ordenamiento, uniones, agrupaciones, funciones de agregación y subconsultas. Mediante la base de datos \texttt{VETERINARIA\_DB}, se logró consultar información relacionada entre propietarios, mascotas, veterinarios, especialidades y consultas médicas.

Además, el desarrollo de consultas propias permitió reforzar el uso combinado de \texttt{INNER JOIN}, \texttt{GROUP BY}, \texttt{HAVING}, subconsultas y funciones de agregación. Esto demuestra que una base de datos correctamente relacionada facilita la obtención de reportes útiles para la toma de decisiones.

\subsection{Recomendaciones}

Se recomienda verificar la conexión al usuario correcto antes de ejecutar las consultas, ya que trabajar con otro usuario puede generar errores relacionados con tablas inexistentes. También se recomienda ejecutar primero las sentencias de creación de tablas e inserción de datos antes de probar las consultas.

Además, es conveniente ordenar y nombrar correctamente las capturas de evidencia para facilitar su inclusión en el informe. En consultas con columnas de texto largas, se recomienda ajustar el tamaño de salida o utilizar Oracle SQL Developer para visualizar los resultados de forma más clara.
