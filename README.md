# featureKaren - Subconsultas SQL

## 📌 Qué se hizo
Desarrollo de las 4 subconsultas para el APE 3 del ejercicio 3:
- Creación de 5 tablas: CLIENTE, PRODUCTO, PROVEEDOR, COMPRA, ENTREGA
- Inserción de datos de ejemplo
- 4 subconsultas SQL para análisis de datos

## 🔍 Subconsultas
1. Clientes que compraron el producto más caro
2. Productos nunca comprados  
3. Proveedores que suministran productos con stock bajo
4. Productos con precio superior al promedio

## 📊 Resultados
- Ana Gomez compró el Monitor 4K ($1500)
- Audífonos Bluetooth y SSD 1TB no han sido comprados
- Carlos Mendoza y Pedro Ramirez suministran productos con stock bajo
- Laptop Gamer y Monitor 4K tienen precio sobre el promedio

## 🛠️ Tecnología
Oracle SQL / PLSQL
